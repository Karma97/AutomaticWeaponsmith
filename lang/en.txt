# Automatic Weaponsmith - language file
#
# How to translate:
# 1. Copy this file and name the copy after your language, for example zh.txt or de.txt.
# 2. Keep it in this folder and save it as UTF-8.
# 3. Translate only the text to the right of the "=" sign. Do not change the name on the left.
# 4. Keep words in {curly brackets} exactly as they are. The mod fills in the real value there.
#    You can move them to a different place in the sentence.
# 5. \n means a new line. Lines that start with # are ignored.
# 6. Start the game and choose your file in the settings (F12) under "Language".
#
# If a line is missing, the mod uses the English text for it. New versions of the mod may add
# new lines, and the log file (BepInEx\LogOutput.log) tells you how many are missing.
